# Lista de Contactos - React & Context API

Aplicación de gestión de contactos (CRUD completo) construida con React y Context API, consumiendo la API REST pública de 4Geeks para persistir los datos.

## Stack técnico
- React + React Router
- Context API (manejo de estado global)
- API externa: [playground.4geeks.com/contact](https://playground.4geeks.com/contact/docs)

## Funcionalidades
- **Listado de contactos**: vista `Contact` con todos los contactos guardados
- **Crear / editar contacto**: vista `AddContact` con formulario reutilizado para ambas acciones
- **Eliminar contacto**: con modal de confirmación antes de borrar
- **ContactCard**: componente para mostrar cada contacto de forma individual

## Cómo correrlo localmente
```bash
npm install
npm start
```
